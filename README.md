# Prompt Craft

Create a modern, fast, SEO-optimized AI prompt library website.

GOAL:

A clean website where users can browse, search, and copy AI prompts for different professions (teachers, students, freelancers, marketers, developers).

STYLE:

- Minimal, premium SaaS design

- Inspired by Notion, Linear, OpenAI

- Dark mode default

- Clean typography, lots of spacing

- Subtle hover effects, no heavy animations

- Mobile-first responsive design

PAGES:

1. Homepage

2. Category pages (profession-based)

3. Individual prompt pages

4. Blog page

5. About page

HOMEPAGE STRUCTURE:

- Hero section with headline: "AI Prompts Built for Real Work"

- Large search bar (main focus)

- Category cards (Teachers, Students, Freelancers, Marketing, Developers)

- Trending prompts section

- Latest prompts section

- Simple footer

PROMPT PAGE STRUCTURE:

- Title

- Short description

- Large prompt box (copy-ready)

- Copy button (very prominent)

- Example output section

- Related prompts section

FEATURES:

- Search prompts by keyword

- Copy-to-clipboard button for prompts

- Category filtering

- Clean URL structure (SEO friendly)

- Mobile responsive design

- Fast loading performance

- Basic SEO metadata (title, description)

DATABASE:

Prepare structure for prompts:

- title

- slug

- category

- profession

- prompt content

- tags

IMPORTANT UX:

- Users should be able to access all content without signup

- No authentication required

- Focus on instant access and fast copying of prompts

GOAL EXPERIENCE:

User lands → searches or clicks category → opens prompt → copies instantly in 1 click
